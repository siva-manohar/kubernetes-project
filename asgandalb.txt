
Autoscaling Groups:

Scaling ===> Increasing and decreasing based on your traffic

Auto Scaling ===> automatic Increasing and decreasing ( human involvement is not needed )


Vertical Autoscaling
   Whenever you are increasing the Server capacity vertically within the same instance then it is vertical autoscaling.

Horizontal Autoscaling
   Whenever you are increasing one more server with the same configuration is called as Horizontal autoscaling.

Loadbalancer/Loadbalancing:

Distributing the incoming user traffic across multiple destinations ( servers ) so that no particular server is overloaded.

https://blog.bytebytego.com/p/ep47-common-load-balancing-algorithms

Different types of loadbalancers:

1. Application Loadbalancer

Handles: HTTP=80 and HTTPS=443

SSL Certifcate = Secure Socket Layer

Ex: Web application, Microservices, Mobile applications.

On which layer the application layer exist ===> Application Layer


2. network Loadbalancer

Handles: TCP, UDP and TLS

On which layer the application layer exist ===> Transport Layer

Ex: Gaming applications, Finance/Banking applications, Realtime stock market applications



3. Gateway loadbalancer

It is used for security data transfer or vulnerability checks


4. Classic Loadbalancer -- Old and depecreted


target group:

A routing ( redirecting/transferring the request ) is happening on a particular group of servers where the traffic routing
